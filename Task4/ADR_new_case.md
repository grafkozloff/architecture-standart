## <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                                                                                        |
|:-----:|:--------------------------------------------------------------------------------------------------------------------------------------|
|   R   | **Надёжность (Reliability)**                                                                                                          |
|  R1   | Все сервисы, включая АБС и интернет-банк, работают 24/7.                                                                              |
|  R2   | Доступность в 99,9%.                                                                                                                  |
|   P   | **Производительность (Performance)**                                                                                                  |
|  P1   | Отклик по всем операциям не превышает несколько миллисекунд для внутренних пользователей.                                             |
|  P2   | Информация по ставкам загружается не дольше, чем за минуту, для сотрудников партнерского кол-центра.                                  |
|  +R   | **+ Ограничения (Restrictions)**                                                                                                      |
|  +R1  | Сетевые соединения для передачи информации по депозитам и ставкам защищаем шифрованием.                                               |
|  +R2  | Доступ к информации по ставкам для сотрудников партнерского кол-центра предоставляется службой безопасности банка.                    |
|  +R3  | Доступ к информации по депозитам и ставкам для сотрудников кол-центров (внутреннего и партнерского) предоставляется только на чтение. |

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- Передача информации по ставкам сотрудникам партнерского кол-центра по электронной почте. При этом будет еще более низкая производительность. Также возникнет сложность с контролем прав доступа к данным.

**Недостатки, ограничения, риски**

- Передача информации по ставкам сотрудникам партнерского кол-центра по SFTP может занимать относительно длительное время.
- Актуальность данных при передача информации по ставкам сотрудникам партнерского кол-центра по SFTP может не соблюдаться.
